### Why Reproducibility Matters?
Reproducibility is the ability to achieve the exact same results using the data, code, and analytical methods of another researcher. It is an important concept in social research as it ensures scientific integrity and allows verification of analysis. By sharing code and the work process, it allows others to check your work, thereby ensuring transparency. It allows others to check if your work was done honestly, and accurately, without errors or mistakes. Moreover, others can check for data fabrication, and misleading results. Hence, it is important in social research.
